Heading 6: Formatting the text

This is a paragraph. Any text may be bold, italic, underlined, strikethrough (deleted).

The text may also be marked (highlighted). And this is a piece of something looks like an inline code inside a regular paragraph.

You can use superscript (X2) or subscript (H2O) symbols.

And you can add hyperlinks like Markdown Guide, footnotes1 (LINE BREAK)
and date/time.2

See also other other add-ons.

Blocks of text

Lists are ordered:

  1. First
  2. Second
  3. Third

or unordered:

  • Bird
  • Chat
  • Dog

To-Do lists are ordered:

  1. Todo…
  2. Done!

or unordered:

  • Not complete yet…
  • Complete!

and also nested:

  • Parent
    • Child
      1. Grandchild

Definition list:

Frau
weiblicher erwachsener Mensch
Ehefrau

This is a citation (blockquote).

And code block looks like with a code language definition:

/python/
print("Hello, World!")

and without it:

Some text.
Product Qty Price
Apples 2 $3.00
Bananas 3 $1.50
Cherries 1 $4.00
Total 6 $8.50
