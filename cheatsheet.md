# **Mark Editor — Keyboard Shortcuts Cheat Sheet**

## **File Operations**

| Command      | Shortcut       |
| :---         | :---:          |
| *New File*   | `Ctrl+N`       |
| *Open...*    | `Ctrl+O`       |
| *Reopen*     | `Ctrl+Shift+O` |
| *Save*       | `Ctrl+S`       |
| *Save As...* | `Ctrl+Shift+S` |
| *Convert...* | `Ctrl+E`       |
| *Quit*       | `Ctrl+Q`       |
